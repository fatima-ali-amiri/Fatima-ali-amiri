📚 BookNest – Smart Book Discovery System

Description: A web-based book discovery and recommendation system developed using Python and Flask.

Live Website: "Open BookNest" (https://fat33maali112.pythonanywhere.com/)

GitHub Repository: "View Source Code" (https://github.com/fatima-ali-amiri/BookNest)

Technologies:

- Python
- Flask
- BeautifulSoup
- Pandas
- Scikit-learn
- HTML & CSS
- CSV and JSON
- Git & GitHub

- Collection of 1,000 books
- Book title search
- Category and price filters
- Rating filters
- Individual book details
- Favourite books functionality
- Top-rated book recommendations
- Content-based recommendations using TF-IDF and Cosine Similarity
- Responsive user interface

Deployment: PythonAnywhere

Status: Live 🚀
